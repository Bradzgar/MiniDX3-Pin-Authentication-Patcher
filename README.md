The original 6-byte JLE instruction sequence:
 0F 8E 90 00 00 00 -> JLE LAB_00406432

Inverted JG instruction sequence:
 0F 8F 90 00 00 00 -> JG LAB_00406432

 Place pathcer.py in folder with MiniTools.exe and run python.

 Patcher will allow you to use any pin to access device and then you can change the pin. Any stored data will be preserved.
